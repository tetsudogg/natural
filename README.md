# Natural

美しい大自然のなかで、ただ過ごすゲーム。ブラウザで動きます。

目的やスコアはありません。森の渓谷を歩き、木々や小川、虫の声を楽しみます。
気に入った景色を見つけたら「眺めモード」にして、テレビやプロジェクターに映しっぱなしにできます。

## 遊び方

| 操作 | キー |
| --- | --- |
| 歩く／走る | `W` `A` `S` `D`（矢印キーも可）／ `Shift` |
| 見回す | マウス（画面をクリックすると操作できます） |
| 一人称／三人称の切り替え | `C` |
| 眺めモード | `V`（眺めモード中は `C` でカメラの動きを切り替え） |
| 全画面 | `F` |
| 時間の速さ | `T`（標準：1日 約40分／早回し：1日 約2分／現実と同じ） |
| 画質 | `Q`（高／中／低。重いときは自動で下がります） |
| 操作の表示 | `H` |

いる場所と時間はブラウザに自動で保存され、次に開いたときはそこから始まります。

## 今できること（段階1：試作）

- 渓谷の地形、小川と小さな滝、杉林と広葉樹の森、草、岩
- 朝もや、昼、夕焼け、星と月の夜。夏の夜にはホタル
- 環境音（風、葉ずれ、川、滝、鳥、セミ、スズムシ、フクロウ、足音）。音はすべてその場で合成しています
- 光と空気感：木漏れ日の光の筋、接地部分の自然な陰、まぶしい光のにじみ、流れる雲、谷にたまる朝もや、写真のような色合い
- 眺めモード（画面表示を消して景色だけを映す。描画を1秒30回に抑えて長時間でもPCに優しく）

テント、焚き火、料理、リュック、スマホとドローン配達は次の段階で入れます。

## 開発

```sh
npm install
npm run dev      # 手元で動かす
npm run build    # dist/ に書き出す
```

- Three.js + TypeScript + Vite
- 地面・岩・苔・樹皮・葉・シダは [Poly Haven](https://polyhaven.com) の写真素材（CC0、無料・表記不要）を使っています。`src/assets/` に縮小済みで入っているので、ゲームは外部から何も読み込みません。取り直すときは `python3 scripts/fetch_textures.py`（Pillow が必要）
- 花、空、水、音はプログラムで生成しています（費用ゼロ）
- `main` に入ると GitHub Actions が GitHub Pages に公開します
